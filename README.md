# Image Compressor

> Compress JPEG, PNG, and WebP images in your browser. Reduce file size without losing quality. 100% local.

## Features

- **Privacy-first** — No backend, no uploads, no tracking. Everything happens in your browser.
- **No installation** — Works directly in the browser.
- **Accessible** — ARIA-compliant, keyboard navigation, screen reader support.

## Tech Stack

- Canvas API
- [Vite](https://vitejs.dev/)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Testing

```bash
npm run test:run
```
